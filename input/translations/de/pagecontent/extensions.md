Das Modul definiert sechs eigene Extensions und liefert acht
FHIR-R5-Backport-Extensions (Präfix `backport-`) mit, die R5-Semantik in die
R4-Repräsentation tragen — die vollständige Liste mit gerenderten Definitionen
zeigt die [Artefaktübersicht](artifacts.html). Die moduleigenen Extensions:

| Extension | Zweck |
| --- | --- |
| [Akronym](StructureDefinition-mii-ex-studie-akronym.html) | Studienakronym |
| [Eligibility](StructureDefinition-mii-ex-studie-eligibility.html) | Referenz auf Ein-/Ausschlusskriterien |
| [Ethikvotum](StructureDefinition-mii-ex-studie-ethikvotum.html) | Ethikvotum |
| [Finanzierung](StructureDefinition-mii-ex-studie-finanzierung.html) | Finanzierung |
| [Quell-Register](StructureDefinition-mii-ex-studie-quell-register.html) | Quellregister-Kennzeichen |
| [Rekrutierung](StructureDefinition-mii-ex-studie-rekrutierung.html) | Rekrutierungsstand/-ziel/-start |
| [Studienregister](StructureDefinition-mii-ex-studie-studienregister.html) | Referenz auf das Studienregister |
