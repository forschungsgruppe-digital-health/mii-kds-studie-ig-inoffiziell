extensions (prefixed `backport-`) that carry R5 semantics into the R4
representation — see the [artifacts summary](artifacts.html) for the complete
list with rendered definitions. The module's own extensions:

| [Finanzierung](StructureDefinition-mii-ex-studie-finanzierung.html) | Funding |
| [Quell-Register](StructureDefinition-mii-ex-studie-quell-register.html) | Source register flag |
| [Rekrutierung](StructureDefinition-mii-ex-studie-rekrutierung.html) | Recruitment status/target/start |
