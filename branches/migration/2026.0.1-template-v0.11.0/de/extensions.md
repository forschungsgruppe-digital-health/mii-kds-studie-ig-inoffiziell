## Extensions

 Diese Seite enthält Übersetzungen aus der Originalsprache, in der der Leitfaden verfasst wurde. Informationen zu diesen Übersetzungen und Anweisungen zum Abgeben von Feedback zu den Übersetzungen finden Sie [hier](translationinfo.md). 

Das Modul definiert sechs eigene Extensions und liefert acht FHIR-R5-Backport-Extensions (Präfix `backport-`) mit, die R5-Semantik in die R4-Repräsentation tragen — die vollständige Liste mit gerenderten Definitionen zeigt die [Artefaktübersicht](artifacts.md). Die moduleigenen Extensions:

| | |
| :--- | :--- |
| [Akronym](StructureDefinition-mii-ex-studie-akronym.md) | Studienakronym |
| [Eligibility](StructureDefinition-mii-ex-studie-eligibility.md) | Referenz auf Ein-/Ausschlusskriterien |
| [Ethikvotum](StructureDefinition-mii-ex-studie-ethikvotum.md) | Ethikvotum |
| [Finanzierung](StructureDefinition-mii-ex-studie-finanzierung.md) | Finanzierung |
| [Quell-Register](StructureDefinition-mii-ex-studie-quell-register.md) | Quellregister-Kennzeichen |
| [Rekrutierung](StructureDefinition-mii-ex-studie-rekrutierung.md) | Rekrutierungsstand/-ziel/-start |
| [Studienregister](StructureDefinition-mii-ex-studie-studienregister.md) | Referenz auf das Studienregister |
